# JKCalcHub

A responsive collection of 30 browser-based calculators for everyday math, finance estimates, students, health, and business. Built with static HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser or serve this directory with any static web server. The homepage contains an interactive standard calculator, searchable calculator directory, and category filters. Individual tools use `calculator.html?id=...`.

## Site information
- `about.html` explains the site and calculator approach.
- `contact.html` provides a feedback contact.
- `privacy.html`, `terms.html`, and `disclaimer.html` explain privacy practices and limitations.
- `robots.txt` and `sitemap.xml` provide basic crawl discovery for the configured custom domain.

## Calculator categories
- Everyday: standard math, percentages, age, date differences, discounts, tip and bill split, fuel, and unit conversion.
- Finance: loan EMI, SIP, lumpsum, FD, RD, GST, PPF/EPF, HRA, interest, and inflation estimates.
- Student: CGPA, SGPA, attendance, and exam marks/grade.
- Health: BMI, TDEE/BMR, water, ideal weight, and pregnancy due date estimates.
- Business: profit margin/markup, freelance hourly rate, and social media earnings estimates.

All outputs are general estimates, not professional advice. Currency selection changes formatting only and does not convert amounts or use live exchange rates.
